# 安装与启用

[← 文档导航](README.md)

本指南适用于已在本机使用 DeepSeek Harness 的用户。安装后，你会获得一个“工程任务”工作台和一个“工程化开发引擎”会话预设。

下面的 npm 安装命令获取最新发布版；`0.29.0` 起包含四档流程、项目 Skill/Rule 初始化与可选 SonarQube CI 审核。

## 1. 安装插件

确认 pnpm 可用，将插件添加到所用的 Web profile。以下命令使用 `web`。

```sh
dsh plugin --profile web add @godv61/dsh-task-engine
```

如果你正在 Harness 源码目录开发，使用：

```sh
pnpm dsh plugin --profile web add @godv61/dsh-task-engine
pnpm dsh web --no-open
```

不写版本号会安装 npm 上的 `latest`；需要固定版本时再追加 `@<版本>`。

已有 Web 进程时，先关闭该进程再启动，避免端口冲突。通过 `dsh plugin` 安装会将插件加入对应 profile；仅在任意目录执行 `npm install` 不会完成工作台挂载。

## 2. 检查安装结果

重启后检查两个位置：

- 侧边栏出现 **工程任务**，打开后可以选择工作区。
- 新建会话时，可以选择 **工程化开发引擎**。

没有看到入口时，先确认安装和启动使用的是同一个 profile，再检查启动日志中的插件加载错误。命令报找不到 pnpm 时，需要先准备好 pnpm 环境。

## 3. 配置第一个项目

1. 在工作台顶部选择工作区。
2. 在「自适应流程」页查看四档路径，并按需设置 SonarQube 审核。
3. 如需自己的技能或规则，在对应页面安装，再挂载到元技能；内置核心 Skill 可在配置 Rule 时复制为同名项目 Skill。
4. 保存配置，在使用“工程化开发引擎”预设的会话中描述任务。

后续在“任务台账”查看阶段、实施项与验证审核记录。项目初始化会管理根目录的 `AGENTS.md`：先查看或生成草稿，再确认保存。

## 两种预设的区别

| 位置 | 决定什么 |
| :--- | :--- |
| 会话中的“工程化开发引擎” | 是否启用 `dev_task`、配套技能和工程人设。 |
| 四档自适应流程 | 每个新需求按复杂度独立选择阶段与门禁。 |

如果切换到未挂载插件 agent 的其他会话预设，该会话不会启用这套任务工具；侧边栏工作台仍可使用。
