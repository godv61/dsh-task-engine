# 功能规划

[← 文档导航](README.md)

本页记录讨论中的方向，不代表已发布功能。当前 npm 版本为 0.23.0；实现范围在开始编码前确认。

## 优先讨论：自定义流程

三个内置流程继续开箱即用，用户可以复制成自己的模板，通过可视化表单配置：

| 能力 | 建议第一版范围 |
| :--- | :--- |
| 阶段 | 添加、重命名、删除和调整顺序。 |
| 条件 | 为阶段设置人工确认、实施完成、验证、审核或必填产物。 |
| 资源 | 自由添加、替换和移除阶段技能/规则。 |
| 产物 | 配置名称与必填字段。 |
| 提交 | 配置提交阶段、方式、格式与文件范围要求。 |
| 复用 | 保存到项目，支持配置导入/导出。 |

建议采用左侧阶段列表、右侧配置、底部流程预览。第一版以顺序流程为主；分支、循环和并行需要单独设计证据失效和任务恢复逻辑。

运行中的任务保持原流程快照。多次验证、审核和人工确认应绑定到各自阶段，不能自动复用前一个阶段的通过状态。配置保存还应保留 verify_command 等已有项目字段。

## 后续体验方向

- 资源导入：文件选择取消、大包进度、分块上传与取消。
- 资源维护：来源与版本记录、升级差异预览、备份和恢复。
- 工作台：未保存内容保护、台账扩展、语言与可访问性完善。
- 项目展示：真实工作台截图、案例和插件市场收录。

## 产品范围

本项目服务本机个人开发工作台。多用户服务器的会话权限架构不列为当前版本的必修项。日常改进优先解决工作区目标清晰、文件误操作、任务连续性和操作反馈。
