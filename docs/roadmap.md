## 当前能力边界

| 能力 | 状态 |
| :--- | :--- |
| 三个内置流程（`standard`、`agile`、`minimal`） | ✅ 已发布，开箱即用 |
| 阶段选择技能、规则归属技能 | ✅ 已发布 |
| 任务台账、验证与审核回执、提交门禁 | ✅ 已发布 |
| 项目级与个人级资源安装、来源保留 | ✅ 已发布 |
| 四档任务级流程、元技能、项目扫描 init、可选审核期 SonarQube | 🛠️ 开发中，未发布 |
| **自由编辑流程阶段与条件** | ❌ **不在计划内** |

**关于自定义流程**：让使用者自行设计阶段、条件与提交流程曾被评估，结论是**不列入计划**——
任务级四档流程覆盖常见开发复杂度，用户可挂载项目技能；自由编辑状态机仍不在当前范围。

旧任务继续读取 `.dsh/eng.json`；新任务用 `.dsh/meta.json` 管理元技能挂载，复杂度在任务创建时确定。

## 后续体验方向

- 资源导入：文件选择取消、大包进度、分块上传与取消。
- 资源维护：来源与版本记录、升级差异预览、备份和恢复。
- 工作台：未保存内容保护、台账扩展、语言与可访问性完善。
- 项目展示：真实工作台截图、案例和收录信息。

## 产品范围

本项目服务本机与团队分支开发中的个人会话。多用户服务器的会话权限架构不列为当前版本的必修项。日常改进优先解决工作区目标清晰、文件误操作、任务连续性和操作反馈。
