# 功能规划

[← 文档导航](README.md)

本页记录**讨论中的方向，不代表已发布功能**；是否实现、何时实现都在开始编码前单独确认。
已发布的能力与版本变化见[更新日志](CHANGELOG.md)。

## 当前能力边界

| 能力 | 状态 |
| :--- | :--- |
| 三个内置流程（`standard`、`agile`、`minimal`） | ✅ 已发布，开箱即用 |
| 阶段资源绑定（技能、规则挂到具体阶段） | ✅ 已发布 |
| 任务台账、验证与审核回执、提交门禁 | ✅ 已发布 |
| 项目级与个人级资源安装、来源保留 | ✅ 已发布 |
| **自由编辑流程阶段与条件** | ❌ **不在计划内** |

**关于自定义流程**：让使用者自行设计阶段、条件与提交流程曾被评估，结论是**不列入计划**——
它把流程设计的负担转嫁给使用者，而三个内置流程已覆盖个人项目的常见需要。代码中不存在该能力的
实现；相关尝试保留在非发布分支，不在 `main` 上。

需要调整时，可修改项目根目录的 `.dsh/eng.json` 改变阶段资源绑定，或直接在三个内置流程中选择。

## 后续体验方向

- 资源导入：文件选择取消、大包进度、分块上传与取消。
- 资源维护：来源与版本记录、升级差异预览、备份和恢复。
- 工作台：未保存内容保护、台账扩展、语言与可访问性完善。
- 项目展示：真实工作台截图、案例和收录信息。

## 产品范围

本项目服务本机个人开发工作台。多用户服务器的会话权限架构不列为当前版本的必修项。日常改进优先
解决工作区目标清晰、文件误操作、任务连续性和操作反馈。
