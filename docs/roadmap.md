# 功能规划

[← 文档导航](README.md)

自定义顺序流程的使用方式见[流程配置](configuration.md)。本页列出后续方向，不表示已经支持。

- 流程复用：多模板库、版本差异预览、运行中任务的显式迁移。
- 流程扩展：分支、循环、并行，以及与之配套的证据失效和任务恢复语义。
- 资源维护：来源与版本记录、升级差异预览、备份和恢复。
- 资源导入：分块上传、进度与取消。
- 工作台：台账扩展、多语言及可访问性完善。
- 项目展示：案例与插件市场收录。

本项目服务本机个人开发工作台。优先解决工作区目标清晰、文件误操作、任务连续性和操作反馈；多用户服务器权限架构不属于当前改造范围。
