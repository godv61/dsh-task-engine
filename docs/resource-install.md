# 安装技能和规则

在 Harness 打开「工程流程」，先选择目标工作区，再进入「技能」或「规则」。

1. 点「安装技能」，在系统文件选择器中选择技能文件夹；或点「安装规则」选择一个 Markdown 文件。
2. 查看预览中的名称、正文、目标路径、文件数、体积和冲突提示。
3. 选择项目或个人范围。切换范围后重新预览。
4. 点「确认安装」。成功后列表刷新；同名资源拒绝覆盖。新安装的技能仍需在「流程配置」中挂到对应节点。

技能根目录包含 UTF-8 的 `SKILL.md`，frontmatter 提供单行 `name` 和 `description`。名称使用小写字母、数字和连字符，例如 `code-check`。规则名称来自 `.md` 文件名，同样采用上述格式。支持 UTF-8 BOM 和 CRLF；其他文本编码请先转换。技能的脚本与附件保留原始字节，安装不会执行脚本。

项目范围写入所选工作区 `.dsh/skills` 或 `.dsh/rules`；个人范围写入 `$DSH_HOME/skills` 或 `$DSH_HOME/rules`（默认用户主目录下 `.dsh`）。删除确认框显示实际路径；删除不经过回收站。

浏览器选择器访问浏览器所在电脑的文件；高级目录模式访问 Harness 主机的目录。两者在远程部署中可能不是同一台电脑。浏览器不会暴露源文件绝对路径或符号链接元数据，不能宣称浏览器上传也完成了源链接检查。

导入限制为 1000 文件、100 MB 总量、20 MB 单文件、20 层相对路径；清单和规则正文最多 1 MB。自动排除 `node_modules`、`.git`、`__pycache__`、`.venv`、`venv`、`.cache` 和 `.DS_Store`。禁止路径穿越、Windows ADS、保留名称、大小写重名及文件/目录冲突。高级目录扫描拒绝链接和特殊文件。合法包的上传仍会在内存中编码及校验，大包经远程网关的容量和并发性能未完成压力测试。

预览不写入目标。确认时重新校验内容和目标的摘要，并使用独占创建避免覆盖现有资源；失败时清理本次新建的技能目录。此机制不构成针对具有同等主机文件权限的恶意进程的完整隔离。
