# 0.40.1 — 文件范围校验与任务恢复

发布日期：2026-11-05（Asia/Shanghai）。

当验证计划登记了尚不存在的路径，而该路径随后成为目录时，0.40.0 的指纹计算会抛错，导致任务从台账消失、状态和验证难以恢复。0.40.1 修复了这条故障链路。

- create、scope、plan、plan_execution、plan_verification 统一校验具体普通文件，拒绝目录、链接父路径、越界路径和通配符；继续允许预先登记新文件、无扩展名文件及方括号路由文件。
- 活动任务的输入无效时仍可查看标题、阶段与进度，台账、Markdown 导出和 status 给出具体路径及所属验证组。
- 多个无效验证组可以逐个重写清单恢复；旧证据保留，未修正的输入仍阻止放行。
- verify 和 dispatch 在启动命令或子代理前核对相关输入，避免执行后才发现其它验证组损坏。
- 指纹不跳过目录或链接；只读测试配置的变化继续影响证据有效性。工作区授权边界保持独立。

本版继续支持 DSH 0.2.1-rc.3、rc.4、rc.5。本地构建、类型检查与完整回归通过：446 项中 439 通过、7 跳过、0 失败；新增 14 项文件范围回归。跳过项不计入已验证能力。

遇到文件范围错误时，先查看 status.file_scope_problems，使用 scope、plan_execution 或 plan_verification 将对应项修正为具体文件，再核对并重跑缺失、失败或过期的验证。无需手动修改任务 JSON。
