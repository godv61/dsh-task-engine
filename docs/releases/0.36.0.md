# 0.36.0

项目 Skill 初始化在较大仓库中可能因发现预算、查阅轮数或格式重试而反复失败。本版保留已有证据并改善恢复行为，同时提供更充足、可调整的生成时间。

- 目录发现未完成时允许生成注明范围的地图；已知路径遗漏及缺少文件证据仍会校验。目录发现预算不变。
- 查阅接近轮数或工具预算时进入整理阶段。格式、长度和已知路径问题在原上下文中修复一次，避免重复扫描；网络重试使用独立读取记录。
- 单项生成默认 10 分钟，页面可选 5/10/20/30 分钟；查阅、思考、正文与重试共用预算。继承默认模型的思考等级，取消固定 110 秒提前收尾，并为后台及轮询留出收尾时间。
- 项目地图负责模块与导航，业务能力负责角色、流程和业务规则。业务能力可参考本轮地图全文，但仍须独立读取源码；没有地图也可独立生成。内置生成和外部提示词复制共用上下文。
- 新增大型项目耗时说明和外部生成提示词复制入口，转换插件专用工具要求，便于使用能读取源码的编码助手生成并自行安装、挂载。
- 重新生成已有草案使用页面内可见的确认与取消，明确显示目标；没有有效新草案时保留旧内容。

## 缓存与升级说明

新作业不再写入项目 `.dsh/init-jobs/` 或本机磁盘缓存。后台作业保存在进程内存中，已结束结果保留 30 分钟，总数最多 100 条并自动淘汰。DSH 重启会清空后台作业；浏览器已经保存的草案仍可恢复，尚未取回的结果可能需要重新生成。旧版作业文件仅兼容读取，不自动删除。

继续支持 DSH `0.2.1-rc.3`；工程会话、默认委派策略及 Sonar 审核流程不在本次改动范围内。

## 验证

类型检查、构建、自动回归、npm 安装包黑盒和 DSH rc.3 契约检查通过。真实大型仓库完成五项初始化与提案检查，验证菜单切换、刷新恢复及项目文件保留。生成结果仍是待审阅草案，提示词约束不能替代业务事实核实。
