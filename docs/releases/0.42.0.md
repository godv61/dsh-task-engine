# 0.42.0

工程化开发引擎新增 DSH 0.2.2-rc.5 支持，可与 DSH 原生智能体团队同时启用。

## 新增与调整

- 工程实施项关联 DSH 原生任务板、成员会话和本轮消息回执。Lead 通过 `dev_task` 派发、续跑、取消和收取，使用原生面板与工具查看成员和任务。
- 独立实施项可在文件范围不重叠时并行。同一实施项可复用成员。实施成员只在本轮授权内创建或修改已登记的普通文件。
- Lead 保留需求确认、强制 Skill、独立审核、真实测试和最终验收职责。原生任务板记录成员执行进度。测试与验收依据工程台账的回执。
- 新增精确宿主版本 `0.2.2-rc.5`，保留 `0.2.2-rc.3`、`0.2.2-rc.1` 和 `0.2.1-rc.3/rc.4/rc.5` 的兼容检查。

## 验证与范围

- 使用 rc.5 公共 SDK 及离线脚本模型核对预设、并行、文件冲突、成员复用、取消恢复、读写门禁和真实测试回执。
- 在隔离浏览器中复测 `deepseek-v4.1-flash`、`Max`、工程预设和原生团队同时开启。公共 SDK 也核对了派发和续跑的模型请求参数。真实外部模型的端到端验收仍待进行。
- 团队文件权限覆盖同一宿主中的受控编辑。终端、删除、重命名和依赖完整父会话历史的工作由 Lead 在收齐成员结果后处理。

## 升级

升级插件后重新加载工程预设。双开时按 [README 的团队协作说明](../README.md#与-dsh-智能体团队协作) 操作。
