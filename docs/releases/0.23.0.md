# 0.23.0 修改清单与发布说明

[← 文档导航](../README.md)

## 本次实现

| 分类 | 问题 | 处理 |
|---|---|---|
| 安装 | 目录逐级浏览步骤多，Web host 原生选择器可能无 provider | 默认使用浏览器系统文件选择器，技能选目录，规则选 .md；高级主机路径入口保留 |
| 安装 | 写入前看不清目标与内容 | 预览名称、正文、数量、大小、路径、同名冲突，确认后写入 |
| 安全 | 路径、体积、链接与失败残留处理分散 | 公用导入模块，全包校验、摘要绑定、独占写入、失败清理 |
| 安全 | client workspace 只有路径黑名单 | 优先查询 Harness workspaceRegistry；未知路径拒绝，旧 host 使用已有严格注册策略 |
| 并发 | 读取内容后才读取文件版本仍可能覆盖并发修改 | 先读版本再读内容，逻辑 revision 和文件版本共同检查 |
| UI | 技能/规则两套重复界面，状态不统一 | 共用资源管理器，卡片、搜索、来源筛选、目标说明、加载/错误/成功状态 |
| UI | 删除动作不够明确 | 显示实际目标和永久删除说明，提供保留按钮 |
| UI | 弹窗键盘操作不完整 | Escape、焦点限制、关闭后恢复焦点 |
| UI | 台账难定位任务 | 标题/任务/分支搜索，风险/阶段筛选，验证/审核/更新时间 |
| 错误 | 保存和台账读取失败提示不全 | 捕获传输与校验错误、保存防重、读失败可见；损坏记录报错 |
| 文档 | 历史文案夸大防篡改保证 | 明确 hash、CAS、hook、workspace registry 各自能力与限制 |
| 发布 | 仓库与包元信息不完整 | repository/homepage/bugs、MIT LICENSE、Windows CI、发布包行为验证 |

## 删减与保留

删除重复技能/规则 UI 和旧目录复制实现；替换 14 条仅搜索复制器源码文本的旧断言。保留已有 Remote 安装方法以兼容旧客户端；保留高级主机目录导入和现有流程预设。未删除用户已有技能、规则、任务或流程配置。

## 后续建议

后续优先讨论可视化自定义流程、资源导入反馈和资源维护。详细范围见[功能规划](../roadmap.md)。产品定位为个人本机工作台，会话级服务器隔离不列为当前版本必修项。

## 验证与发布

以[测试报告](../testing/0.23.0/测试报告.md)记录实际结果。源代码与 npm 发布各自验证；GitHub CI 未完成时不能称已通过。市场 PR 只添加 `data/plugins/godv61__dsh-task-engine.yml`，按[贡献指南](https://github.com/awesome-dsh-plugin/awesome-dsh-plugin/blob/main/contributing.md)检查，npm 关联来自 package.json repository。
