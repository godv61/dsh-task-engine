# 0.41.1 — DSH 0.2.2-rc.3 子代理兼容修复

发布日期：2026-11-16（Asia/Shanghai）。

本版支持 DSH 0.2.2-rc.3，继续支持 0.2.2-rc.1 及 0.2.1-rc.3、rc.4、rc.5。新宿主使用 Node.js >=24.9.0，旧宿主保持 Node 22 回归。

- 修复新宿主 `startActivation` 参数移到顶层后，只读分析委派、实施 spawn/fork 和独立审核无法正常启动的问题。
- 三个派发入口统一在启动前选择新旧参数形式，不在启动失败后换参数重试，避免重复创建子代理。台账继续以稳定会话 ID 关联证据，并保留新宿主的名称信息。
- 更新宿主依赖、兼容声明和 CI，增加真实公共 SDK 子代理回归：只读写入拒绝、文件读取、结构化回传、取消、资源释放及取消后再次派发。

本地完整回归 456 项（449 通过、7 跳过、0 失败），P0 143 项通过；构建、双端类型检查、npm 安装包黑盒及精确 rc.3 源码契约通过。rc.3、rc.1 公共 SDK 的真实托管子代理验收通过，最低支持的 0.2.1-rc.3 类型与预设验收通过。宿主由本地脚本适配器驱动，不访问外部模型 API；本轮未做桌面页面及真实模型验收。详细范围见 [适配验收](../testing/dsh-rc223-compatibility.md)。

升级桌面程序后，请在插件管理中更新 `@godv61/dsh-task-engine` 到 0.41.1 并重启。任务流程、项目 Skill/Rule 挂载和历史数据无需迁移。
