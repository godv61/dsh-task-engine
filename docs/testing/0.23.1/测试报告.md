## 新增用例覆盖

1. 当前需求阶段披露 scope/acceptance_criteria；返回准确缺项；未定义字段拒绝时整个记录保持不变；修正字段后可继续。
2. 敏捷流程仅披露 scope，设计阶段披露自身字段，无记录阶段返回空列表。字段提示从冻结配置读取，不改变历史任务。

新增测试在修复前均失败，避免只断言实现自身返回成功。状态查询一致性、真实提交、验证过期及失败技能等既有回归一并执行。

## 实机证据的适用范围

rc.3 在真实业务需求中走完同一任务的审批、8项实施审核、测试技能、真实命令验证、范围受控本地提交及哈希回写。新增文档后过期的验证和测试技能回执实际阻止过提交，重验后恢复。rc.5 的状态提示修复及本次字段披露有自动化证据；由于用户暂停业务重跑，没有本版完整业务重跑证据。

实机包含观察方干预，不算完全自主。业务结构树真实联调未通过；额外布局与虚拟滚动需求未实施。没有以这些未完成事项宣称产品业务全通过。

## 发布限制

仅已执行检查可标通过。包测试使用模拟宿主与干净安装，不能覆盖所有 Harness 版本、模型行为或共享部署权限场景。技能指引不能强制模型报告内容准确，所有完成结论仍须结合证据审查。
