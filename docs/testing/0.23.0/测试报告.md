## 剩余限制

- 主机工作区注册不等于会话级授权；本地任务 JSON 没有签名。需要 Harness 调用上下文与可信存储支持才能完成多用户边界。
- 整包内存上传未做 100 MB 远程网关/并发压力测试；浏览器源符号链接不可辨识；未覆盖断电中断和恶意同权限进程抢改目录。
- 实机为 Windows/Chromium、当前 Harness 源码；没有执行 macOS/Linux、其他浏览器或真实模型从建任务到提交的全流程。本地 hook 不能替代服务端 CI 验证。
- 原生选择器取消、完整屏幕阅读器与深色主题尚未形成专门验收矩阵；全量语言字典、资源升级和备份属于后续建议。
- profile 缺少单独声明的 Harness peer 会产生警告；源码主机与干净 npm 安装验证都通过，不能推断所有第三方 profile 都兼容。
- GitHub Actions 与 npm 公网发布状态单独记录，不以本地成功代替。

## 清理与发布状态

实机技能附件与规则文件均核对 SHA-256 一致，两个一次性资源已清理并确认目标不存在；源码 fixture 留在评测工作目录，不进入发布仓库。源历史 163 个 blob 和当前待发布文件的常见凭据模式扫描无命中；模式扫描不保证发现所有形式的秘密。
