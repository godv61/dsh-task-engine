# 自定义顺序流程

项目的自定义流程使用 schema 1 定义与 custom: 标识，包含阶段、条件、产物、资源和提交设置。解析器拒绝分支、循环、引用错误和不完整定义；预设保留原追加绑定语义。

任务按创建时快照执行。自定义确认、验证和审核必须属于当前阶段；未修改内置预设版本，已发布任务继续使用旧证据语义。状态输出披露当前条件与产物定义，绑定技能不依赖阶段的中文名称。

配置写入合并已有项目字段，并同时检查浏览器读取时的摘要和 fs 文件版本，避免遗漏 verify_command 或并发覆盖。Remote 客户端与 host 共用自定义 JSON 解析定义；打包后的客户端编解码回归检查新字段完整传输。

Git 钩子按任务快照识别提交消息捕获组；有快照的任务不依赖当前项目配置能否解析。手动自定义提交通过工具时请求人工批准，Git 钩子保留其他检查。

新编辑器文案集中到类型化中文词典，页面内确认框处理草稿离开与阶段删除。独立插件采用工具输出断言和真实 Harness 页面验收，未调用 monorepo 专用快照与文档生成器。

验证记录见 [自定义流程测试](../../docs/testing/custom-workflows/测试执行记录.md)。
