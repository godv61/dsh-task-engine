# 安装预览与工作区验证

资源安装由浏览器采集文件或主机扫描目录，服务端统一校验相对路径、内容、目标及资源名称。确认请求重新计算摘要，独占创建防止覆盖；只有本次创建的技能目录属于失败清理范围。技能和规则 UI 共用组件，避免范围、预览和错误处理分别演进。

浏览器选择器适用于 Web profile，不依赖主机 native picker provider。浏览器文件 API 不保留源链接信息；主机扫描才能验证源链接。整包内存校验使实现简单，但大包上传的进度、取消、并发和内存预算需要后续设计。

Harness 注册工作区是可用的主机可信路径来源；不存在该服务时保留旧 host 策略，不把注册表故障降级为宽松模式。注册不提供调用会话身份。任务 CAS 在内容读取前取得文件版本，防止版本在读取期间变化时被误认为新版本内容。

验证包括实际文件系统的导入/回滚、故障注入时保留现有兄弟文件、注册表故障不降级、确定性任务竞态、发布 tarball 安装和 Web 实机操作。旧静态复制器断言被行为测试替代；其余历史 P0 静态断言仍明确计为断言而非 E2E。
